# Wippy Registry Go API

Go protobuf messages and Connect clients for the
[Wippy module registry protocol](https://github.com/wippyai/module-registry-proto).

## Generation

Check out the protocol repository beside this repository as
`../module-registry-proto`, then run `make generate-proto`.
The generator configuration is in [buf.gen.yaml](buf.gen.yaml).

The root license and notice cover the generated bindings and remain in place
when bindings are regenerated.
